# Formula Lab 项目文档索引

Formula Lab 是一个面向《Linux系统与编程实践》大实验 2 的公式图片转 LaTeX 工具网站。项目目标不是只完成一个演示页面，而是按照现代 Web 产品的方式构建一个可运行、可解释、可扩展的完整系统。

根目录 [DESIGN.md](../DESIGN.md) 是 Formula Lab 的 UI 设计语言单一来源。后续实现页面、模板和样式时，以该文件为准。

## 文档治理规则

当前文档采用“少而稳定”的治理方式：不再为每次讨论新增独立文档。后续决策优先写入现有文档，避免出现多套事实来源。

## 第一版架构决策

- Web 框架：Django
- 数据库：PostgreSQL
- 异步任务：Celery
- 消息队列：Redis
- 公式识别：PaddleOCR Formula Recognition，本地默认模型为 `PP-FormulaNet_plus-S`
- 兼容引擎：pix2tex / LaTeX-OCR，可用于对照与回退
- 前端形态：Django Template + 原生 JavaScript + KaTeX
- 运行方式：Docker Compose
- UI 形态：SpaceX-inspired 顶部导航任务控制台
- UI 设计语言：根目录 `DESIGN.md`，主参考 SpaceX DESIGN.md
- 项目目录：`/Users/tim/Desktop/shared-Linux/formula-lab`

## 当前阶段

当前阶段已经进入第一版产品实现。代码已覆盖基础运行时、数据模型、异步任务、PaddleOCR 与 pix2tex 可切换识别适配、上传与重试 API、Mission Control 风格页面、Projects-first 工作区、Review Drawer、Paper Preview、项目级 `.tex/.md` 导出和本地测试环境。本机开发默认使用 PaddleOCR Formula Recognition，启动命令为 `make local`。第一版主流程是：

```text
上传公式图片 -> 选择或创建项目 -> 创建识别任务 -> 后台识别 -> 进度页轮询 -> 结果页展示 -> 项目工作区校对与导出 -> 历史记录回看
```
