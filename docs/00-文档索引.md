# Formula Lab 项目文档索引

Formula Lab 是一个面向《Linux系统与编程实践》大实验 2 的公式图片转 LaTeX 工具网站。项目目标不是只完成一个演示页面，而是按照现代 Web 产品的方式构建一个可运行、可解释、可扩展的完整系统。

根目录 [DESIGN.md](../DESIGN.md) 是 Formula Lab 的 UI 设计语言单一来源。后续实现页面、模板和样式时，以该文件为准。

## 第一版架构决策

- Web 框架：Django
- 数据库：PostgreSQL
- 异步任务：Celery
- 消息队列：Redis
- 公式识别：pix2tex / LaTeX-OCR
- 前端形态：Django Template + 原生 JavaScript + KaTeX
- 运行方式：Docker Compose
- UI 形态：SpaceX-inspired 顶部导航任务控制台
- UI 设计语言：根目录 `DESIGN.md`，主参考 SpaceX DESIGN.md
- 项目目录：`/Users/tim/Desktop/shared-Linux/formula-lab`
