# Landing 第三阶段 Product Preview Reveal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the landing page's final scroll state from a CTA button ending into a semantic mini product workspace preview.

**Architecture:** Keep the existing React/Vite landing island and ScrollTrigger timeline. Product UI preview is rendered in DOM/CSS through `WorkspaceRevealOverlay`; WebGL remains responsible only for manuscript, scan, and formula particles. Scroll state continues to flow from `ScrollDirector` through CSS variables and a ref bridge, with no per-frame React state.

**Tech Stack:** Django static assets, React 19, TypeScript, Vite, GSAP ScrollTrigger, Three.js/react-three-fiber, KaTeX, Node guard scripts.

---

## Scope

This plan implements only the approved third-stage Landing behavior. It does not implement real project editing, real collaboration backend, real OCR calls, React Router, or a full Project Workspace embed.

The deliverable is a visually convincing, maintainable Product Preview Reveal:

- Left project context.
- Center paper workspace.
- Right formula review inbox.
- Collaboration signals.
- CTA actions embedded inside the workspace, not floating as the main ending.
