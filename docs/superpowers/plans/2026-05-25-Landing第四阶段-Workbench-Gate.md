# Landing 第四阶段 Workbench Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the landing page's final Product Preview Reveal with a restrained Workbench Gate ending that leaves one clear `Enter Workbench` action.

**Architecture:** Keep the existing React/Vite landing island, GSAP ScrollTrigger director, Three.js manuscript canvas, and CSS-variable animation bridge. Replace the final DOM overlay with a smaller `WorkbenchGateOverlay` component, retune `ScrollDirector` to expose gate-focused variables, and remove product-preview CSS/tests from the landing terminal state.

**Tech Stack:** Django static assets, React 19, TypeScript, Vite, GSAP ScrollTrigger, Three.js/react-three-fiber, KaTeX, Node guard scripts.

---

## Scope

This plan implements only the approved fourth-stage landing ending. It does not rebuild the full landing page, add backend APIs, change OCR/model behavior, add Lenis, copy Luke Baffait's frame-sequence technique, or redesign Project Workspace.

The deliverable is a desktop-first scroll story that ends with:

- The formula constellation and hero text fully gone.
- The manuscript visually centered, decoded, and reduced in dominance.
- A minimal final overlay with one main action: `Enter Workbench`.
- No final Product Preview grid, project tree, review inbox, collaboration badge, or competing CTA.
