# 项目总览

## 项目名称

Formula Lab Mission Control。

中文定位：一个 SpaceX-inspired 的论文公式识别、审校与导出工作台。

## 项目背景

本项目服务于《Linux系统与编程实践》大实验 2。实验要求基于 Ubuntu 22.04、Python 3.10 与 Django 实现一个在线工具网站，用户可以上传公式图片，网站将图片转换为 LaTeX 公式文本，并能在 Markdown 或 Typora 中正确渲染。

课程验收要求包括：

- 网站可以顺利打开。
- 可以从“测试用图片”中选择公式图片上传。
- 可以将公式图片转换为 LaTeX 文本。
- LaTeX 文本可以复制。
- 页面整洁、美观，符合使用习惯。
- 进度条能够真实体现转换进度。
- 网页中可以直接渲染 LaTeX 公式效果。

## 产品目标

本项目不只实现课程验收所需的最小功能，而是按一个真实产品原型来设计。视觉和交互上采用 SpaceX-inspired Mission Control 方向，把公式识别过程表达成一次可观察的任务序列，并进一步把识别结果沉淀到论文项目工作区中：

- 支持真实公式识别模型，而不是只对测试图片写死结果；当前本机默认使用 PaddleOCR Formula Recognition。
- 支持异步任务，避免用户上传后页面长时间阻塞。
- 使用数据库保存历史识别记录。
- 支持 PaperProject、BatchMission 和 FormulaItem，把单次识别升级为论文公式资产管理。
- 支持 Project Workspace 中的公式队列、Inspector、Paper Fit Preview、Review Drawer 和项目级导出。
- 提供清晰的任务状态、进度提示、错误提示和结果页。
- 采用 Docker Compose 管理运行环境，降低 Mac 开发和 Ubuntu 验收之间的环境差异。
- 使用黑白高对比、顶部导航、任务阶段、mission log、telemetry 等界面语言形成记忆点。

## 核心用户

第一类用户是课程验收场景中的学生和老师。学生需要快速演示完整流程，老师需要看到网站能够稳定运行、流程清楚、功能真实。

第二类用户是未来可能继续使用这个工具的人，尤其是用 LaTeX 写课程论文、竞赛论文或科研论文的同学。他们关心上传图片、得到 LaTeX、校对公式、观察论文适配情况、复制或导出公式、查看历史记录这些高频操作是否顺滑。

## 核心能力

Formula Lab 第一版应具备以下能力：

- 上传 PNG、JPG、JPEG 等常见图片格式。
- 保存上传图片。
- 创建公式识别任务。
- 使用 Celery worker 在后台调用可配置公式识别模型，默认本机路径为 PaddleOCR Formula Recognition。
- 保存识别结果、任务状态、进度和错误信息。
- 在进度页持续展示任务阶段。
- 在结果页展示原图、LaTeX 文本和公式渲染结果。
- 在结果页展示 Paper Fit Preview，辅助判断公式是否适合当前论文栏宽。
- 一键复制 LaTeX。
- 在历史记录页查看过去的识别任务。
- 以用户可读的 Mission Code 展示任务编号，避免把 UUID 直接暴露为主要界面标识。
- 在 Projects-first 工作区中管理公式条目、批次、审校状态和 `.tex/.md` 导出。

## 非目标

第一版暂不实现以下内容：

- 用户注册与登录。
- 多人权限隔离。
- 在线部署到公网。
- Nginx 生产部署。
- 完整批量上传与自动切分。
- GPU 调度。
- 多模型评测平台。
- 在线 PDF 编译预览。
- 本地 LLM 公式解释与自动修复。

这些能力可以作为后续扩展，但不进入第一版核心范围。
